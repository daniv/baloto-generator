Lottery Page Objects Test Planning

Maximum meaningful coverage of the currently exposed page object classes: BalotoPage, RevanchaPage, and MilotoPage.

Coverage strategy: validate public behavior from top to bottom while exercising private parsing, locator, normalization, structural, and state branches indirectly. Shared behavior marked BR or BRM is intended to be implemented with pytest.mark.parametrize and a game_type parameter.

Priority model

P0Critical game identity or data-integrity protection. P1Core extraction, validation, and malformed-fixture behavior. P2Contracts, metadata, normalization, and secondary behavior. P3Warnings, missing test data, cleanup, and non-functional regression protection.

Game codes

BBaloto only. RRevancha only. MMiloto only. BRShared Baloto and Revancha behavior; use parametrization. BRMShared behavior across all three games; use parametrization.
